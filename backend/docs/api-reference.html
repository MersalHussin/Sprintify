Sprintify API Reference

REST API for team-based project management with sprints, tasks, and AI assistance.

Base URL: http://localhost:4000 · Generated from source · 2026-06-24

General Information

  • Authentication: All routes except GET /health require Authorization: Bearer <firebase-id-token>
  • Content-Type: Send JSON bodies with Content-Type: application/json
  • Response envelope: { "status": "OK", "message": "...", "data": { ... } }
  • Rate limits: Global 100 req/min per user/IP; AI routes 5 req/min
  • Team roles: manager (write access) and member (read + comments)
  • Pagination: Optional page and limit query params on list endpoints
  • Object IDs: MongoDB ObjectId strings (24 hex characters) for resource path params

Endpoints

GET /health Health

Liveness and dependency check for MongoDB and Redis. Does not require authentication.

Authentication: None (public)

Query Parameters

None

Success Response

    "redis": "ok" | "error"
  }
}
Example
{
  "status": "ok",
  "checks": { "mongo": "ok", "redis": "ok" }
}

Status Codes

CodeDescription
200All dependencies healthy
503One or more dependencies failed
